# Будильник (Alarm Clock)

Чистое приложение-будильник для **Android 6.0+** (версия 2.7). Без рекламы, аккаунтов и доступа в интернет. Собирается **без Gradle** — обычным набором сборочных инструментов Android.

## Возможности

- **До 15 одновременных будильников.** Список показывает только созданные будильники: время, название, дни недели, переключатель вкл/выкл. Тап по строке — редактор (время, повтор с днями, название, удаление).
- Звук: системные звуки будильника или свой файл с телефона, прослушивание перед выбором (одна настройка звука на все будильники).
- Экран звонка поверх блокировки: крупные часы, дата, название, две большие кнопки.
- **«Остановить»** — отложить на 5–30 мин с лимитом повторов (счётчик у каждого будильника свой).
- **«Отключить»** — выбор способа: **«На сутки»** (погасить текущий звонок, расписание сохраняется) или **«Совсем»** (выключить только этот будильник целиком).
- «Решить пример», чтобы отключить: 2 или 3 числа в примере (`12 + 7 − 4`, `3 × 4 + 6`).
- Нарастание громкости, своя громкость звонка, вибрация, автоостановка.
- Тёмная и светлая темы (в светлой выделение голубым; применяются и к экрану звонка).
- «Проверить звонок» в настройках.
- Блок «Надёжность»: проверяет уведомления, ограничения батареи и показ поверх блокировки.
- **Восстановление после перезагрузки**: Direct Boot (`LOCKED_BOOT_COMPLETED`), настройки в device-protected storage, постановка каждого будильника двумя независимыми каналами (`setAlarmClock` + `setExactAndAllowWhileIdle`) с per-alarm дедупликацией срабатываний. Действует и при смене времени/часового пояса.
- **Дозвон при разблокировке**: если телефон был выключен/заблокирован в момент звонка и время прошло не более 15 мин назад — звонок прозвучит при разблокировке/открытии приложения, а не молча переносится на завтра.
- Встроенный журнал диагностики: кнопка «Выгрузить» отправляет журнал в мессенджер через системное меню «Поделиться».
- Миграция с версии 2.6: старый одиночный будильник автоматически становится первым в списке (id 1).

## Сборка

Нужны: JDK 17+, Android SDK build-tools 34.0.0 (aapt, zipalign, apksigner, d8) и `android.jar` платформы android-34.

```bash
ANDROID_JAR=/путь/android-sdk/platforms/android-34/android.jar \
BT=/путь/android-sdk/build-tools/34.0.0 ./build.sh
```

Результат — подписанный `AlarmClock.apk`. Версия задаётся переменными `VERSION_CODE` / `VERSION_NAME`.

Старые SDK с `dx` тоже поддерживаются: скрипт выбирает `d8` или `dx` автоматически.

## Структура

```
app/src/main/
  AndroidManifest.xml
  java/ru/alarm/clean/   — MainActivity, RingActivity, AlarmService, AlarmReceiver,
                           BootReceiver, AlarmScheduler (ядро: до 15 будильников),
                           NextAlarm, NativeBridge
  res/                   — drawable, значения
  assets/                — интерфейс (index.html + app.js, WebView)
build.sh                 — скрипт сборки без Gradle
```

Хранение конфигурации: список будильников — ключ `alarmIds` («ID;ID») и per-alarm ключи `a<ID>.enabled / hour / minute / repeat / days / label / triggerAt / snoozeAt / snoozeCount / lastFiredAt`; общие настройки (звук, громкость, лимиты, пример для отключения) — плоские ключи. RequestCode каналов: звонок `1000 + id*2` (+1 резерв), откладывание `1200 + id*2` (+1 резерв). Id передаётся через intent extra `alarmId`.

Ключ подписи (`release.keystore`) в репозиторий не входит — соберите и подпишите своим ключом, либо положите файл `release.keystore` рядом со скриптом (пароль задаётся `KS_PASS`).
