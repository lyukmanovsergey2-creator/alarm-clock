# Будильник 2.10

Чистое приложение-будильник для Android 6.0+ (APK). Без рекламы и аккаунтов.
Работает в фоне точно, будит даже после перезагрузки — и не мешает лишним звуком.

## Экран (три равные трети)
1. **Цифры** — ближайший будильник, статус, кнопка «+» и шестерёнка настроек.
2. **Список будильников** — все созданные будильники; тап открывает редактор.
3. **Одна кнопка** — создание будильника (во время звонка — «Остановить» и «Отключить»).

## Возможности
- До 15 будильников одновременно; лишних строк в списке нет.
- **Персональные настройки у каждого будильника** (в 2.10): мелодия, громкость,
  нарастание, автоостановка, откладывание с лимитом, вибрация, «Решить пример»
  и чисел в примере — всё в редакторе будильника, плюс кнопка «Проверить звонок»
  настройками именно этого будильника. У будильников со старых версий настройки
  переносятся из общих — ничего не теряется.
- **Стиль «Часов» iOS** (в 2.10): список — сгруппированные карточки; светлая тема
  белые карточки на сером фоне и голубые тумблеры, тёмная — лаймовый акцент.
- **Группировка «Сегодня / Позже»**: включённые на сегодня (до полуночи) — в
  первой группе, остальные — «Позже», выключенные — «Выключены».
- Редактор будильника **раскрывается из строки** (анимация от строки, не шторка).
- **Вибро-отклик** на тап тумблера и на удаление.
- **Удаление свайпом влево** (в 2.10): тянете строку влево (можно начать и с
  тумблера) — появляется компактная красная кнопка «Удалить». Довели тумблер до
  левой трети экрана (зелёная зона) и отпустили — будильник удалён. Отпустили
  раньше — строка плавно возвращается на место, ничего не удаляется.
- Дни недели (Пн–Вс), «Будни» / «Выходные» определяются автоматически.
- Свой звук из файла (музыка с телефона) + системные звуки будильника.
- Название будильника (показывается на экране звонка и в уведомлении).
- Откладывание 5–30 мин, лимит откладываний (теперь у каждого будильника).
- Нарастающая громкость, собственная громкость будильника, вибрация вкл/выкл.
- Автоостановка звонка (1–30 мин или никогда).
- «Решить пример», чтобы отключить (цифровая клавиатура на экране звонка).
- «Пропустить ближайший звонок» для повторяющегося будильника.
- «Проверить звонок» — тест звука и экрана прямо сейчас.
- Тёмная и светлая тема (применяется и к экрану звонка).
- Планирование через `setAlarmClock` — не засыпает в Doze, значок в статус-баре.
- Блок «Надёжность»: уведомления, ограничения батареи, показ поверх блокировки.
- Блок «Диагностика»: журнал работы, «Выгрузить» отправляет текстом.

## Проверка обновлений (необязательная)
- По умолчанию выключена; включается в настройках: переключатель
  «Проверять новые версии» → согласие на доступ в интернет.
- Если включена — раз в сутки при открытии приложения выполняется один
  запрос к странице релизов (GitHub). Нашлась новая версия — шторка
  «Обновить / Позже». «Позже» — предложение повторится при следующей
  проверке.
- Кнопка «Проверить сейчас» — разовая проверка независимо от таймера.
- Во время звонка проверка молчит и расписание будильников не трогает.
- Обновление скачивается фоном в кеш приложения (с показом процентов),
  затем открывается системный установщик — как при установке любого
  приложения. APK в память попадает только после вашего нажатия
  «Обновить»; устанавливается тот же подписанный файл.

## Сборка
`ANDROID_JAR=/путь/android.jar ./build.sh` (нужны JDK 17, aapt, zipalign, apksigner, d8).
Подпись: `release.keystore` (пароль `alarmclock`) — для обновлений используйте тот же ключ.
