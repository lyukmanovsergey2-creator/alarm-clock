# Будильник (Alarm Clock)

Чистое приложение-будильник для **Android 6.0+** (версия 2.6). Без рекламы, аккаунтов и доступа в интернет. Собирается **без Gradle** — обычным набором сборочных инструментов Android.

## Возможности

- Будильник с повторами по дням недели (Пн–Вс), одноразовый/ежедневный.
- Звук: системные звуки будильника или свой файл с телефона, прослушивание перед выбором.
- Экран звонка поверх блокировки: крупные часы, дата, две большие кнопки.
- **«Остановить»** — отложить на 5–30 мин с лимитом повторов.
- **«Отключить»** — выбор способа: **«На сутки»** (пропустить ближайший звонок) или **«Совсем»** (выключить целиком).
- «Решить пример», чтобы отключить: 2 или 3 числа в примере (`12 + 7 − 4`, `3 × 4 + 6`).
- Нарастание громкости, своя громкость звонка, вибрация, автоостановка.
- Название будильника, тёмная и светлая темы (применяются и к экрану звонка).
- «Пропустить ближайший звонок» и «Проверить звонок» в настройках.
- Блок «Надёжность»: проверяет уведомления, ограничения батареи и показ поверх блокировки.
- **Восстановление после перезагрузки**: Direct Boot (`LOCKED_BOOT_COMPLETED`), настройки в device-protected storage, двойная установка будильника (`setAlarmClock` + `setExactAndAllowWhileIdle`) с дедупликацией срабатываний.
- **Дозвон при разблокировке**: если телефон был выключен/заблокирован в момент звонка и время прошло не более 15 мин назад — звонок прозвучит при разблокировке/открытии приложения, а не молча переносится на завтра.
- Встроенный журнал диагностики: кнопка «Выгрузить» отправляет журнал в мессенджер через системное меню «Поделиться».

## Сборка

Нужны: JDK 17+, Android SDK build-tools 34.0.0 (aapt, zipalign, apksigner, d8) и `android.jar` платформы android-34.

```bash
ANDROID_JAR=/путь/android-sdk/platforms/android-34/android.jar \
BT=/путь/android-sdk/build-tools/34.0.0 ./build.sh
```

Результат — подписанный `AlarmClock.apk`. Версия задаётся переменными `VERSION_CODE` / `VERSION_NAME`.

Старые SDK с `dx` тоже поддерживаются: скрипт выбирает `d8` или `dx` автоматически.

## Структура

```
app/src/main/
  AndroidManifest.xml
  java/ru/alarm/clean/   — MainActivity, RingActivity, AlarmService, AlarmReceiver,
                           BootReceiver, AlarmScheduler, NextAlarm, NativeBridge
  res/                   — drawable, значения
  assets/                — интерфейс (index.html + app.js, WebView)
build.sh                 — скрипт сборки без Gradle
```

Манифест: `directBootAware` для приложения/приёмника/сервиса, намерения `LOCKED_BOOT_COMPLETED`, `BOOT_COMPLETED`, `TIME_SET`, `TIMEZONE_CHANGED`, `MY_PACKAGE_REPLACED`, `QUICKBOOT_POWERON`.

Ключ подписи (`release.keystore`) в репозиторий не входит — соберите и подпишите своим ключом, либо положите файл `release.keystore` рядом со скриптом (пароль задаётся `KS_PASS`).
